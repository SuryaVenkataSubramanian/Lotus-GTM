# Document360 Lotus: GTM command center

Docs as code, synced both ways. This repo holds the go-to-market launch kit for Document360 Lotus.

| Path | What it is |
| --- | --- |
| `/` | GTM command center: every launch asset, with the full resource in a pop-up |
| `/landing` | Waitlist landing page, with the GradientASCII hero animation |
| `/newsletters/lotus-newsletter-existing-customers.html` | Customer newsletter (HTML for Ortto) |
| `/newsletters/lotus-newsletter-trial-demo-leads.html` | Trial and demo leads newsletter (HTML for Ortto) |
| `/newsletters/lotus-banner.png` | Email banner: Document360 ⟷ Lotus ⟷ GitHub |
| `/lotus-hero/LotusHero.jsx` | React hero for the live site (`npx shadcn@latest add @react-bits/GradientASCII-JS-CSS`) |
| `/assets` | Lotus mascot, Document360 wordmark, product screens |

Static site, no build step. Deploys on Vercel as is.
